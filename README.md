# xr-design

基于 Svelte 的 WEB 桌面端组件库

## 项目开发

```bash
pnpm serve
```

## 项目构建

### 构建组件库（CommonJS 版本）

```bash
pnpm build:cjs
```

### 构建组件库（ES Module 版本）

```bash
pnpm build:esm
```

### 构建组件库（UMD 版本）

```bash
pnpm build:umd
```

### 构建组件库类型（Types）

```bash
pnpm build:types
```

### 构建组件库（CommonJS + ES Module + UMD + Types）

```bash
pnpm build:dist
```

### 构建预览页

```bash
pnpm build:site
```

## 代码检测

### 代码检查（不修复）

```bash
pnpm check
```

### 代码检查（带修复）

```bash
pnpm check:fix
```
